## 🏗️ Featured project

### 🍌 [Nano-Banana — End-to-End DevOps Pipeline](https://github.com/Musstaphaa/DevOps-journey)

> Python Flask app → Docker → Jenkins CI/CD → AWS EKS → Prometheus + Grafana

| Phase | What was built |
|-------|---------------|
| 🐳 Phase 1 | Dockerised Flask + PostgreSQL with Docker Compose — local stack running in one command |
| ☁️ Phase 2 | Terraform provisions full AWS VPC + EKS cluster automatically |
| 🚀 Phase 3 | App deployed to EKS — live on public AWS ELB URL, DB credentials secured |
| ⚙️ Phase 4 | Jenkins declarative pipeline — git push triggers full build, scan, push, deploy |
| 📊 Phase 5 | Prometheus + Grafana via Helm — real-time cluster monitoring on EKS |

**Real problems solved:** Docker-out-of-Docker socket permissions · t3.micro ENI/RAM constraints · IAM role auth between Jenkins and EKS
